# Site rules

This folder is the source of a website on the tailnet: everything you publish from it is visible to every device on the tailnet.

- Write content only in the format described in `FORMAT.md`. You never write HTML; a builder turns your data files into pages within a few seconds of each save.
- After saving, read `BUILD.md` and fix any file it lists as skipped.
- The Daily Seek lives in `news/`; every other publication gets a folder of its own, as `FORMAT.md` describes.
- A publication uses its own name and masthead. Never use the name, logo or masthead lettering of a real newspaper.
- Headlines, summaries and page text come from the feeds or your own writing as plain text, never as markup.
